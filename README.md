# Another World — Archaeology

A long-term research project tracing the **development history of every
release** of Eric Chahi's *Another World* (a.k.a. *Out of This World*).

This is **not** a piece of software with end users. It's an
archaeological dig: catalog every release/port, extract their assets,
and use comparative analysis to reconstruct a "genealogy" of the
codebase — which port introduced which feature, which bug, which
data-layout change.

Methodology is modelled on **MAME's approach to ROM preservation**:
original release files are identified and tracked by checksum;
metadata and code live here, the actual fixtures live in a sibling
archive repo.

## Sibling repos

This project is split across four coordinated repositories. They are
designed to be cloned **side-by-side** in the same parent directory:

| Repo | What | Cross-link |
|---|---|---|
| **`another-world-archaeology`** (this repo) | Metadata, extractors, research notes, issue tracker | — |
| [`another-world-archive`](https://github.com/ArqueologiaDigital/another-world-archive) | Passive archive of original release fixtures | `original_files/` symlink → `../another-world-archive` |
| [`another-world-source-reconstruction`](https://github.com/ArqueologiaDigital/another-world-source-reconstruction) | One source tree that builds back to byte-matching binaries for every cataloged release | references this repo's research |
| [`another-world-hacks`](https://github.com/ArqueologiaDigital/another-world-hacks) | Modified versions of releases that exercise archaeology findings | references research notes here |

External tool dependency:
[`AnotherWorld_VMTools`](https://github.com/felipesanches/AnotherWorld_VMTools)
— the Rust toolchain (disassembler, assembler, resource extractors).
Not vendored; clone alongside as a sibling.

## Repository policies (important)

- **Never commit original game files in this repo.** The active
  fixtures live in [`another-world-archive`](https://github.com/ArqueologiaDigital/another-world-archive),
  which is a separate git repository. The `original_files/` directory
  here is a **symlink** to `../another-world-archive`.
- **Provenance is part of the data.** Every entry in
  `metadata.json` records the download URL, download date, and
  ideally a Wayback Machine archive URL.
- **Two-level checksumming.** md5 at the *package* level (the release
  file as distributed, e.g. the zip) and at the *individual extracted
  resource* level. The per-release working directory is named after
  the package md5.
- **Issues live in `issues/`**, one file per issue, with frontmatter
  validated by `tools/issues.py validate`. Every loose end identified
  during work becomes an issue before the conversation moves on. IDs
  are permanent; issues are never deleted (wrong-direction work is
  closed `wontfix` with a reason). `issues/README.md` is
  auto-generated by `tools/issues.py index`.

## Per-release layout

Every cataloged release gets a working directory named by its package
md5sum (e.g. `076117919d1dca51e486f33b8f7817e3/`) with three
subdirectories:

- `original/` — the unpacked source release (zip extracted, ADF
  mounted, etc.)
- `bin/` — individual resources extracted from the release's bank /
  pak / ROM, named `0x<index>-<TYPE>.bin`
- `disasm/` — disassembled bytecode (target output)

The intent: each release ends up with a parallel tree of
regenerated, source-like artifacts (disassembled bytecode, polygon
data, palettes, etc.) so trees can be diffed across releases.

## Getting started

```bash
# Clone this repo plus its siblings side-by-side
mkdir another-world && cd another-world
git clone git@github.com:ArqueologiaDigital/another-world-archaeology.git
git clone git@github.com:ArqueologiaDigital/another-world-archive.git
git clone git@github.com:ArqueologiaDigital/another-world-source-reconstruction.git
git clone git@github.com:ArqueologiaDigital/another-world-hacks.git
git clone https://github.com/felipesanches/AnotherWorld_VMTools.git

# Build the AWVM_Tools toolchain
cd AnotherWorld_VMTools && cargo build --release
```

The `original_files/` symlink in this repo expects
`../another-world-archive` to exist next to it, which the layout above
provides.

## Status

Active research. Most current focus: cross-port byte-match unification

[`docs/content/research/`](docs/content/research/) and the recent
issues).
